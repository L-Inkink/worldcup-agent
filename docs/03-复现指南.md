## 2. 数据源

### 2.1 赛程与赛果 — football-data.org

```
GET https://api.football-data.org/v4/competitions/WC/matches
Header: X-Auth-Token: {FOOTBALL_DATA_TOKEN}
```

返回 2026 世界杯全部场次：`matchday/stage/group/homeTeam/awayTeam/score/status`。`status=FINISHED` 的场次为真实结果（锁定为事实），`TIMED/SCHEDULED` 为待预测场次。免费层限流 10 次/分钟——采集器需带重试与限速。

### 2.2 Elo 评分 — eloratings.net

World Football Elo Ratings（http://eloratings.net），页面数据可通过其 TSV 接口 `http://eloratings.net/World.tsv` 获取（若结构变化则退化为手工整理快照）。取每队当前 Elo 分。

### 2.3 FIFA 排名

FIFA 官网排名页数据量小且变化慢，直接整理为静态 JSON `backend/data/fifa_rankings.json` 随仓库提交（数据版本注明日期）。

### 2.4 快照机制（关键容错）

- Collector 每次成功拉取后，将原始响应规范化并写入 `backend/data/{matches,elo}.json`，附 `fetched_at` 时间戳。
- 任何网络失败 → 读取快照，输出中标记 `data_source: "snapshot"`。
- 仓库必须提交一份可用快照，保证 clone 后零配置可跑。

## 3. 核心算法（Predictor / Rating / Simulator）

### 3.1 综合实力分（rating.py）

对每队计算综合实力分（单位与 Elo 同量纲）：

```
strength = elo
         + w_fifa   * fifa_bonus        # fifa_bonus = (50 - fifa_rank) * 2，上限100（排名越前加分越多）
         + w_form   * recent_form       # 近10场：胜+1/平0/负-1 求和 * 10
         + w_wc     * wc_performance    # 本届场均净胜球 * 30（体现当前状态）
权重：w_fifa = 0.3, w_form = 0.5, w_wc = 1.0
```

说明：Elo 本身已是最强信号，其余为微调项；`wc_performance` 权重最高，体现"本届杯赛状态"对淘汰赛的预测价值。权重为经验值，复现时可在 ±50% 范围调整，不影响架构。

### 3.2 单场比分概率 —— 独立泊松模型（predictor.py）

足球预测经典方法（Maher, 1982）。步骤：

**① 实力差 → 主队胜率期望（Elo 期望公式）**

```
d = strength_A - strength_B          # 中立场地，无主场加成（世界杯淘汰赛）
E_A = 1 / (1 + 10^(-d/400))          # A 队"期望得分"，即 Elo 胜率期望
```

**② 期望得分 → 双方期望进球 λ**

世界杯场均总进球约 2.7（BASE_GOALS = 2.7）：

```
λ_A = BASE_GOALS * E_A ^ 0.85 * 1.1      # 强队期望进球
λ_B = BASE_GOALS * (1-E_A) ^ 0.85 * 1.1
```

指数 0.85 与系数 1.1 为平滑校准项，使 λ_A + λ_B 在实力接近时 ≈ 2.7、悬殊时总进球略升，符合经验分布。

**③ 泊松比分矩阵**

```
P(比分 = i:j) = Poisson(i; λ_A) * Poisson(j; λ_B)    i, j ∈ [0, 8]
```

由矩阵汇总：`p_win = Σ P(i>j)`，`p_draw = Σ P(i=j)`，`p_loss = Σ P(i<j)`；`most_likely_score = argmax P(i,j)`。

**④ 淘汰赛晋级概率（平局 → 加时/点球）**

```
p_advance_A = p_win + p_draw * (0.5 + (E_A - 0.5) * 0.4)
```

即平局后进入加时/点球，强队仍略占优但优势衰减（点球高度随机）。加时后比分展示用 `most_likely_score` 附"(加时/点球)"标记。

### 3.3 逐轮推演与蒙特卡洛（simulator.py）

**确定性推演**（页面主展示）：

```
for round in [32强, 16强, 8强, 4强, 决赛]:
    for match in round:
        if match.status == FINISHED: 采用真实结果
        else: 晋级方 = p_advance 较高一方；展示比分 = most_likely_score
    下一轮对阵 = 按官方赛程树的晋级槽位填充
```

**蒙特卡洛模拟**（夺冠概率分布）：

```
rng = numpy.random.default_rng(seed=2026)     # 固定种子，保证可复现
repeat 10000 次:
    从当前真实赛况出发，每场未赛比赛按 p_advance 伯努利采样晋级方
    记录每队所到达的最远轮次
p_champion[team] = 夺冠次数 / 10000（p_final、p_semi 同理）
```

**回测指标**（可信度证据）：对所有已赛场次，用赛前数据跑 Predictor，统计"胜平负方向命中率"与"晋级方命中率"，写入 `model_backtest` 字段。

## 4. Qwen 推理解释（reasoner.py）

### 4.1 接入方式

DashScope 的 OpenAI 兼容接口：

```python
from openai import OpenAI
client = OpenAI(api_key=os.environ["DASHSCOPE_API_KEY"],
                base_url="https://dashscope.aliyuncs.com/compatible-mode/v1")
# 单场解说 model="qwen-plus"；冠军长文 model="qwen-max"
```

### 4.2 单场解说 Prompt 模板（qwen-plus）

```
系统：你是一名专业足球分析师。基于给定的量化数据，用中文写一段120字以内的
比赛预测分析。只解释数据，不得更改任何数字结论，不得编造数据中没有的信息。

用户：比赛：{home} vs {away}（{round}）
量化依据：
- 综合实力分：{home} {s_home}（Elo {elo_home}，FIFA第{rank_home}，近10场{form_home}，本届场均净胜{gd_home}）
             {away} {s_away}（同上格式）
- 模型输出：{home}胜率{p_win}%，平局{p_draw}%，{away}胜率{p_loss}%
- 最可能比分：{score}；晋级概率：{home} {p_advance}%
请解释为什么模型给出这一预测。
```

### 4.3 冠军推理长文 Prompt（qwen-max）

```
系统：你是一名资深足球战术与数据分析专家。基于统计模型的完整推演结果撰写
冠军预测报告（600-800字，中文），结构：①夺冠热门格局 ②预测冠军的晋级路径
逐轮分析 ③主要威胁 ④结论。只解释数据，不得更改数字结论。

用户：蒙特卡洛10000次模拟夺冠概率Top8：{odds_table}
预测冠军：{champion}（概率{p}%）
其晋级路径与各场预测：{path_details}
模型对已赛场次回测命中率：{backtest}%
```

### 4.4 降级模板

无 key/调用失败时，用 f-string 规则模板生成同结构文本（例："综合实力分 X 高出对手 Y 分，模型给出 Z% 胜率，主要来自 Elo 优势与本届净胜球表现……"），标记 `reasoning_source: "template"`。

## 5. 实现步骤（建议顺序）

按依赖顺序实现，每步有独立验收点：

| 步骤 | 内容 | 验收 |
|-----|------|-----|
| 1 | 项目骨架 + requirements + 数据快照占位 | 目录结构与架构文档一致 |
| 2 | `collector.py`（API + 快照降级） | 断网时仍能返回完整 TournamentData |
| 3 | `rating.py` | 单测：权重计算正确 |
| 4 | `predictor.py`（泊松模型） | 单测：概率求和=1；强队 p_win > 弱队 |
| 5 | `simulator.py`（推演 + 蒙特卡洛） | 单测：固定种子结果可复现；概率求和=1 |
| 6 | `reasoner.py`（Qwen + 模板降级） | 无 key 时输出模板解释 |
| 7 | `pipeline.py` + `api.py` | `python -m agent.pipeline` 产出合法 prediction.json；所有 API 路由 200 |
| 8 | 前端四视图 | `npm run build` 成功；对阵树正确渲染已赛/预测场次 |
| 9 | Dockerfile + 部署脚本 | 本地 `docker run` 拉起完整服务 |
| 10 | 阿里云 ECS 部署 | 公网 URL 可访问 |
